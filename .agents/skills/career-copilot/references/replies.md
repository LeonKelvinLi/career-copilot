# Reply checks and outstanding work

Read current tracker, profile email identity and last check report. Use the candidate's connected mail tools. Explicitly establish what you could search. For Gmail, include archived mail plus Spam and Trash when available (for example supported `in:anywhere` searches); use actual connector syntax and page through relevant results. Don't claim every folder was checked if access is restricted. Don't silently mark mail read, archive, delete or change filters during a read-only check.

Search tracked employer names, role titles and recruiting domains, plus broader application/interview/assessment/rejection terms for untracked replies. Check delivery failures when relevant. An incremental overlap since the last check helps avoid missed late-indexed messages; older pending applications still need coverage. Read full relevant messages rather than classifying from subject snippets alone. Source links and thread IDs stay in `private/`, not GitHub.

Classify each distinct role:

- Receipt: acknowledgment only; no interview inferred.
- Assessment requested: task, duration, deadline and timezone, and who must complete it. Verify completed assessments independently when possible.
- Interview: actual invitation, next action and schedule. Don't create calendar events or send acceptance without scope.
- Rejection: what the employer actually said; no speculative cause.
- Recruiter outreach: a new opportunity, not automatically an application reply. Salary, client identity, sponsorship and location may remain unknown.
- Information requested or delivery failure: precise missing answer/action.

Keep country mismatches, conflicting role titles and expired deadlines visible instead of silently choosing an interpretation. Source dates matter. Update stages using latest evidence; don't regress a more recent completed assessment because you rediscovered an old invite. Verify chronology and link each message to the right role.

Respond in plain language, leading with actions that need the user. A useful pattern is “The main thing is [assessment/interview]. It needs [action] by [date].” Then separate other meaningful replies, rejections and receipts. Include clickable source links for action items. If no actionable reply was found, say “I found no interview invitation in [actual searched scope]”, not “nobody has replied”.

Save a dated report in `private/reports/` with query coverage, messages inspected, source IDs, limitations and tracker changes. Add concrete tasks owned by `me`, `assistant` or `employer`. Mark a task done only on evidence or user confirmation. When asked “what's outstanding?”, check the tracker against relevant newer sources and list: what needs the candidate, what the assistant can prepare within scope, and what is waiting on employers. Keep preparation and publication distinct. A missing account connection means the result is incomplete, not that the inbox is empty.
