# Connect your own Chrome

Ask Codex: **“Help me connect my Chrome browser and check that it works.”**

If you need to do the installation yourself:

1. In the desktop app, open **Settings → Computer Use** and choose **Google Chrome**.
2. Follow any plugin prompt, then use **Install** to reach the official extension listing. Review and approve installation in your own Chrome profile.
3. Back in the app, check that Chrome shows **Manage**.
4. In a Codex chat, select **@Chrome** and ask it to open `https://example.com` and report the page title.

These steps follow the [official OpenAI browser-extension documentation](https://learn.chatgpt.com/docs/chrome-extension), checked October 29, 2026. Availability depends on your app and workspace. If connection fails, check the active Chrome profile, restart Chrome and the desktop app, then try a new chat.
