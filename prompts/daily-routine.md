# Optional daily routine

This is a reusable instruction, not an active schedule. Tell Codex you want a recurring routine and choose a time, timezone, target and action scope. Codex should use the native automation tool when available and report whether it actually created the schedule. No cron job or GitHub Action is installed by this file.

Suggested routine prompt:

> Read the career-copilot skill, my saved profile, private memory and tracker. Check for actionable employer replies using my own connected email and record what you could access. Find current suitable roles matching my preferences, verify official requirements and country eligibility, and avoid duplicate applications. Prepare or submit only within the scope I've explicitly approved. Use my current résumé and natural voice: simple words, real details, no inflated experience or corporate filler. Record verified receipts separately from uncertain submissions. Update tasks for me, the assistant and employers. Notify me about meaningful new replies, deadlines, blockers, failures or completed work. Stay quiet when nothing meaningful changes. Never complete my scored assessments or recordings for me.

The candidate can choose a target of 15 suitable applications a day, another number, or research only. Never use poor matches just to reach a quota. The default target is unset until the candidate chooses it.
